## Chosen finite behavior and differences

The frozen [profile](../FIXED_WINDOW_PLANNER_V1.md) uses caller-declared immutable
windows and signed integer scores. Required/manual membership and precedence are
hard. Optional admission is deterministic preferred-position/score/ASCII ranking,
with explicit hard duration/shot limits and exact u64 common ticks. No window is
silently shortened. Source floating durations/random UUIDs, locale/capture ties,
window resizing and broader solver features are intentionally not copied.

A shortfall remains a proposal; hard choices can exceed the soft target. Empty
plans are refused as an explicit downstream safety policy although source compose
can return an empty composition. These differences are classified, not hidden by
sorting semantic arrays or claiming full M2-03 shadow parity.
