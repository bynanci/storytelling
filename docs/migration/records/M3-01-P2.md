## Contract and failure model

See [profile](../PLANNER_OTIO_REVIEW_V1.md) and
[ADR](../../adr/0004-selected-proposal-artifact-binding.md). The compiler takes its
shot sequence from `planning.plan`, not the original snapshot composition. Selected
asset IDs, hashes and available durations must match. Still source offsets reject;
video audio requires picture-only acknowledgment, explicit audio/effects reject.
Full snapshot validation precedes rendering, even for unselected snapshot content.

The actual artifact bytes are owned privately. The portable bundle is untrusted;
its OTIO member is hashed and checked before recomputing current inputs. Changing
an annotation/whitespace in the proposal also invalidates the artifact identity.
No fresh disk/media state is observed; callers must supply refreshed declarations.
Informative audit/rank annotations are bound, not proof of original planner/audit
execution. Planner clock may include denominators from unselected candidates, so
valid integer multiples of the selected-plan content rate remain admitted.

All approval/executable/source/host flags remain false. There is no trusted key,
replay ledger, signing API, host path, Catalog mutation or package publication.
Rollback uses original composition commands and discards only new outputs.
