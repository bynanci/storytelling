## Actual observed scope

The reproducible [harness](../../../tests/oracles/filmcraft-25-v1/run.py) generates
two seconds of red/bright-green video and a blue still, verifies both through
the native explicit-source CLI, and produces real M1-02 OTIO at common clock 25.
It creates a new empty project and checks real import structured errors, reports
and offline lists, exact 1920×1080/25 fps native settings, all three clip/source
ranges, default neutral intrinsic effects, two probed media items and repeated
source identity. Native allocated IDs are bound in an external occurrence/media
mapping; arbitrary foreign metadata is not claimed to survive.

The actual CPU H.264/YUV420p preview is intentionally scaled to 192×108. FFprobe
independently confirms one video stream, 45 frames, duration 9/5 seconds and
exact presentation times `i/25` for `i=0..44`. All decoded frames are checked:
20 red, five blue and 20 bright green. This proves order/hold durations; exact
native integer ticks separately prove the source trim offsets. Native Save As
and reopen preserve identical inspected sequence data; the host's own OTIO
export is reimported into another isolated project and checked again. Source
hashes, original empty project and read-only input projects remain unchanged.

Actual tool/candidate/harness identities, commands, command exit codes,
stdout/stderr hashes, source/output hashes, ranges and decoded means are in the
committed [receipt](../../../tests/oracles/filmcraft-25-v1/evidence.json). Bulky
generated media, native projects and complete logs remain under its owned run
root; the checked-in harness reproduces the proof. The receipt names the exact
observed candidate and any tracked changes, rather than treating an output
receipt commit as its own historical input.

## Native source boundary and source comparison

Pinned OpenFilm source `7add4762fe8174d76f43b863375ea39b73121e76`,
`packages/media/src/verified-source.ts`, blob
`f7b8b33445fb2a14394d34544a5b97d6d01f267c`, supplies a stronger filesystem
snapshot callback boundary: lstat/O_NOFOLLOW/fstat dev+ino checks, streamed

only bounded real SHA-256 verification of explicitly supplied immutable bytes.
`VerifiedBufferV1` privately owns its checked bytes and cannot be deserialized
from a report. CLI file reads and pre/post host comparisons provide observed
test evidence; they do not implement the upstream filesystem race closure or
authorize future changed files. OF-29 and GAP-04 remain partial beyond this scope.

Independent G2 review accepted the exact SHA2 dependency and buffer contract;
see [review](../DEPENDENCY_REVIEW_M1_03.md) and
