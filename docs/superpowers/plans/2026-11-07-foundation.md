# Storytelling foundation implementation plan

**Goal:** one executable read-only validation slice plus SDLC-aligned architecture and roadmap.
**Architecture:** CLI -> engine -> core; no host I/O in the core/engine.
**Spec:** ../specs/2026-11-07-foundation-design.md
**Tech stack:** Rust 2024 / 1.85.0, serde, serde_json; std-only CLI grammar.

## Global constraints
Preserve MIT and initial history. Synthetic data only. No empty future crates. No claims of FilmCraft integration or file-hash verification. No merge/publish/admin writes.

## Review focus
Unknown and duplicate fields; huge/invalid decimal times; missing references and duplicate IDs; EOF/input-size/I/O failures; valid failure exit codes without writing user data.

## Task 1 — Contract tests and RED
- [ ] Create three-crate workspace and valid/invalid fixtures.
- [ ] Add tests for acceptance, references, duplicate IDs, time bounds, fields and size.
- [ ] Run the tests against an intentionally non-accepting stub in hosted CI; preserve observed RED evidence.

## Task 2 — Minimal validator and CLI
- [ ] Implement private valid rational time, strict wire DTOs and stable error codes.
- [ ] Implement bounded pure engine validation and JSON CLI output with explicit exits.
- [ ] Verify valid input succeeds, invalid input fails without mutation, unit/integration suites pass.

## Task 3 — SDLC and gates
- [ ] Requirements-to-tests traceability, ADRs, task IDs/dependencies, roadmap exit gates, migration, risks, security and contribution templates.
- [ ] Commit Cargo.lock generated by Cargo, pinned toolchain and cross-platform CI.
- [ ] Check markdown links, TOML, JSON fixtures, formatting, clippy, tests and docs.

## Task 4 — Delivery
- [ ] Self-review actual diff; disclose no independent reviewer.
- [ ] Publish the tested tree to an isolated GitHub branch, create Draft PR, inspect exact-head CI.
- [ ] Leave main unchanged; report completed scope, remaining manual gates and next task.
