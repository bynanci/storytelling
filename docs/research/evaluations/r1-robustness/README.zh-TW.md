[R1 數值轉錄](../2026-11-13-gemini-r1/README.zh-TW.md)追加唯讀算術檢查。
原始分數、宣告分組、錯誤旗標、研究結論與檔案均未修改。沒有生成或重新評分，
也沒有新增模型呼叫、真人、holdout、媒體探測或 Host 操作。

在儲存庫根目錄使用 Python 3.12，新增工具只需標準函式庫：

```sh
python scripts/r1_robustness.py
python scripts/test_r1_robustness.py
python scripts/r1_package_checksums.py verify --ref HEAD --worktree
```

第一個命令只將 UTF-8 LF JSON 輸出至 stdout，不寫入來源。
[report.json](report.json) 保留實際輸出及三份原始數值檔案的 SHA-256。
只有 normalized JSON 中的分數與宣告分組參與新計算；另兩份雜湊用於識別脈絡。
位元組一致不等於已證明來源生成條件。新增目錄固定 LF，避免跨平台換行差異。

| 全部 40 個分組未知，不限制分配數 | `[-173/280, +173/280]` |

工具以整數及 `Fraction` 計算；分數為精確值，小數字串僅為六位近似值。
分組界限是**算術極值，不是信賴區間**。1,024／252 是相同案例的敏感度情境，
不是新增樣本。固定 C11–C40 並不代表那些分組經過驗證；全部分組未知時，界限
同時包含正負值。上述結果不能證明工具有益、有害或等效。批次差異也不能指出原因。
