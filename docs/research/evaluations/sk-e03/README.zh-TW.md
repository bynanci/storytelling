# SK-E03 · 必要事實與歸屬回歸案例

[English](README.md) · 繁體中文 · [總議題 #115](https://github.com/bynanci/storytelling/issues/115) · [Issue #120](https://github.com/bynanci/storytelling/issues/120)

本資料包將四種 R1 錯誤模式轉成合成指令遵循案例。[`cases-v1.json`](cases-v1.json) 含中英文提示、輸入、預期不變條件、失敗條件與實際輸出文字擷取。不重製原始文章全文、私人材料或 R1 分數。

## 案例與規則

| 案例 | 模式 | 主要檢查 |
| --- | --- | --- |
| `C03-SYN-01` | 財經公告與新聞報導的歸屬 | 日期、地點、分母、單位、限定詞及來源／說話者歸屬。 |
| `C04-C06-SYN-01` | 機關通知與主辦者建議 | 機關說法範圍、日期／地點及交通建議提供者身分。 |
| `C07-SYN-01` | 資料包缺少必要欄位 | 未知地點、講者與分母保持未解；選填資訊省略須與明確矛盾區分。 |
| `C24-SYN-01` | 並列指標 | 不同母體和單位分開保留；描述性共變不改寫成因果。 |

案例依據 commit `e6b27d852ef259faf392645a8461c7e6dc006302` 的既有技能 W1、W4、W5，以及第 2 修訂版編輯規則。本次沒有發現足以修改編輯規則的缺口，因此不修改規則文件。四個案例均提供英文與繁體中文。

## 輸出與證據限制

JSON 記錄 Codex 在 2026-11-13 撰寫期間套用上述規則產生的精確草稿文字。這是開發演練，不是盲測或獨立模型評估。模型家族記為 GPT-6，但服務端修訂版未公開，因此無法作為可重現的凍結模型結果。案例作者與評估者是同一代理。指令遵循結果為自我檢視；不評敘事品質。機械回歸只核對必要字詞是否出現／未出現及紀錄是否完整，不能證明語意真實或讀者理解。

本次演練未觀察到模型輸出失敗。失敗條件描述可能失敗的情形，沒有冒充成實際失敗紀錄。沒有真人觀察。這不是保留集結果，也不主張技能更準確、更有用或更有效。
