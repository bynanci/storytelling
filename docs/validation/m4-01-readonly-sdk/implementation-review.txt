crate-root backend call on the original immutable byte slices/ID in original
argument order. Only Err is adapted; there is no pre-parser, normalization,
default insertion, second planner/compiler or hashing path. No accepted backend
body changes in this branch. CLI production code also stays unchanged; its only
source addition is a cfg(test) narrative-formatter regression.

Private SourceError retains all five concrete error families. operation() uses
the exact facade function ID; code()/path() read the original fields. Coverage

exclude a CLI envelope and operation metadata. SdkErrorV1 and

wire schema. Display uses identifiers, not parser prose.

serializers normally cannot fail; the receipts do not demonstrate an induced
public-domain-error encoding failure, and no such observation is claimed.
