## 最短操作

1. 維護者在新議題或私人 agreement 紀錄本協議 commit／SHA-256、日期時區、採用範圍、評分與退出規則。現有合併授權不代表已採用這份新研究協議。先完成英文版的工程命令，無須招募就能檢查。
2. 建置固定 `ce73836caa86502933f538821fdbf5dac92c1224`，材料固定 `8e2c08094f6bce70a7507e11ed84265bd98e3820`，使用 ReportV1。保存乾淨來源、建置日誌、工具鏈、執行檔及輸入雜湊、未轉換 stdout/stderr。不能只憑 0.1.0-dev.0 版本字串或相似 JSON 認定是原生執行。helper 的 source_binding_verified 仍為 false；建置鏈是主持人可查驗紀錄，不是獨立簽章證明。
3. 採用後找五位沒看過題目、答案或相關材料的新作者。使用英文版一次性隨機命令分配三個 AB、兩個 BA；A 是普通筆記、B 是原生 CLI。先保存 seed、Python 版本與預定順序，再記匿名碼、日期／時區、曝光史、CLI／JSON 經驗與實際順序。不能把分配表當成五位已參與。
4. 每臂給全新且相同的 shared 起始材料；CLI 臂另給同詞結構化模板及操作卡。兩臂都交口述、兩份構圖及商業判讀，紅傘 C01 僅在 A 構圖。主持人保留 key、完成答案與工程結果，兩臂之間不公布評分。
5. 讀完修改卡後連續計時，包含思考、metadata、錯誤處理、CLI 等待及保存。480 秒停，保存部分稿件，記為未完成並以 480 秒納入中位數。每次 CLI 用核對過的絕對路徑，保存實際 argv、起訖、exit、原始 stdout/stderr、輸入副本和執行檔前後雜湊。每次嘗試使用新檔名；衍生轉換另存，不能蓋掉原始結果。
6. 使用既有 [sessions](../../examples/evaluation/n07-pilot/forms/sessions.csv)、[errors](../../examples/evaluation/n07-pilot/forms/errors.csv)、[feedback](../../examples/evaluation/n07-pilot/forms/feedback.csv)、[cli-calls](../../examples/evaluation/n07-pilot/forms/cli-calls.csv) 的私人複本。另記 screening、開始、退出、替補與實際順序。重複輸入是同一更正事實的手動重寫，重試指令不等於重複輸入；重工另記原因。保存原句及意外回答，主持人解讀另欄。

## 退出與可比較配對

每次開始及退出都保留於 all-started 分母，不把缺值補成零。缺主要觀察的退出不算可比較配對；新作者沿用該 slot 的順序，但不拼接退出者已完成的一臂。取得五份可比較配對或完成五次替補後停止收案；仍不足就記待真人證據，延長必須先另訂前瞻決定。

配對需有曝光篩查、實際順序、協議／材料身分、原生建置和呼叫紀錄、兩臂開始、計時、產物或部分稿、主要評分、歸因及重複輸入。完整紀錄可以是 timeout 或失敗，不可只挑成功者。包裝程式、材料更動或來源未明的紀錄保留為偏差，不冒充原生配對。工程 preflight 不算作者試用。

## 分析與決定

沿用原 rubric：480 秒內改對 S01／S02 和三份稿，保留 S03／S04、動作及紅傘範圍，正確區分 C01、I01、U01。偽造 C01 或 U01 的來源是 major；同一判斷抄到 log 與 claim 不重複算事件，但保留兩處原文。爭議交第二位評分者，未解決留空。

五份可比較配對且必要欄位齊全才按順序計算：

- **Stop：** B 完成少於 3/5，或至少兩位 B 作者有 major，或完成／品質、時間、重複及歸因全無改善。
- **Continue：** B 至少 4/5 完成、沒有 major，歸因事件總數及 major 人數不高於 A，且中位數至少改善一項：時間減少 20%、每人少一次重複輸入、每人少一次歸因錯誤。
- **Narrow：** 其餘情況。小於 20% 的正向時間改善不等於全無改善。

「全無改善」比較完成數、歸因事件／major 人數及兩臂的作者時間、重複輸入、歸因錯誤中位數。作者 timeout 以 480 秒計入，A 時間為零或未知不能算百分比。商業子項、重工及回饋另列，不事後改門檻。五人資料不支持母體效益或統計顯著宣稱。

報告篩查／招募、各臂開始與完成分母、退出、替補、可比較配對、時間、歸因事件與 major 人數、重複輸入、重工、原句回饋及 AB／BA 順序效應。CLI process 時間另列。缺必要證據就寫 **待真人證據**。維護者實際選擇與計算建議分欄，日期／理由未收到就留白。

可重現問題分流至英文版的 **N07-V3-PROVENANCE**、**N07-V3-ATTRIBUTION** 或既有 **N07-UX01**，先保存合成重現再建立具名議題；這些名稱不是新缺陷的證明。原始私人紀錄不公開入庫。這份準備不推薦 release candidate，也不改變 #54、#65 的結案。

工程預演已在 Linux／Rust 1.89.0 執行：11 案各暖機一次、量測五次，預期 exit、重跑一致性及輸入／執行檔雜湊皆通過；U01 仍是 missing、空 evidence。另以合成方式確認分配命令產生 3 AB／2 BA，重跑拒絕覆寫。這些都是工程紀錄，未分配真人；[收據與限制](n07-native-v3.md#preparation-replay-evidence)不代表作者效益或獨立審查。
