# 想訂球場，現在可以用哪個管道？

[English](service-counter.md) · 繁體中文

市民運動中心在上午 11 點發球場預約公告。值班人員要讓市民分清哪個管道能送出新預約、哪個只能查件，下班時還要把櫃台紀錄交給下一班。以下為合成演練。

## 素材卡

| 卡號 | 素材 | 使用邊界 |
| --- | --- | --- |
| S1 | 網站服務紀錄載明，今天上午 10:20 恢復受理新預約。 | 這個時間只適用於網站。 |
| S2 | 櫃台紀錄載明，服務電話可查既有預約，電話新預約仍暫停。本班開了三張查件收件單。 | 收件單沒有登記查件結果或不重複人數。 |
| P1 | 值班主管希望只在交班便箋末尾留一欄，供填寫待複查的收件單號。 | 是否有待複查案件仍要看個案紀錄。 |

## 讀本 A

要訂球場，現在可透過網站送出新預約。服務電話可查既有預約，電話新預約仍暫停。網站在今天上午 10:20 恢復受理。

## 讀本 B

網站在今天上午 10:20 恢復受理。要訂球場，現在可透過網站送出新預約。服務電話可查既有預約，電話新預約仍暫停。

## C · 交班便箋

本班開了三張查件收件單。服務電話可查既有預約，電話新預約仍暫停。

待複查的收件單號（如有）＿＿＿＿

## 修改卡

- **R1**　S1 更正了網站恢復受理的時間，應為上午 10:35。
- **R2**　主管取消 P1 提議的「待複查的收件單號」欄。

## 主持人用

給首次閱讀的市民看其中一份公告內文。先問「你第一個注意到什麼？哪句話讓你這樣想？」再問「如果你現在要訂球場，你會怎麼做？你根據哪一句？」逐字記下回答，再給第二版。

- **盲讀判準**　A 預期先注意可用網站送件，B 預期先注意網站恢復的時間。另記讀者能否選對新預約的管道。回答「現在可以上網訂，電話只能查既有預約」有稿內依據。「10:20 起網站和電話都能訂」把網站時間及功能推及電話。
- **來源對照**　A、B 均引用 S1、S2。C 引用 S2、P1。兩張修改卡各從原稿開始，均收回三稿。
- **R1**　A、B 各把 10:20 改為 10:35，C 原樣交回。只改 B 會漏改 A。在 C 增寫「10:35 恢復電話預約」還會破壞電話只可查件的事實。
- **R2**　只刪 C 末尾的空欄，保留三張查件收件單及電話服務範圍。三張收件單無法支持「三人已成功預約」或「三件都待複查」。
