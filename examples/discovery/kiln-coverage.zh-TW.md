# 開窯第一眼

[English](kiln-coverage.md) · [情境總覽](../README.zh-TW.md)

導演讀完剪接助理的簡報，要能選擇開場畫面，並指出哪一拍還要找素材。A、B 都是給同一位導演的書面剪接簡報。C 是給製片的缺鏡便箋。素材與稿件均為合成，供文字試讀。下列文字不能直接當作影片對照 CLI 的 JSON 輸入。

## 作者素材

| 卡號 | 素材 | 使用邊界 |
| --- | --- | --- |
| S1 | 陶工日誌記載，燒製前關窯門，隔天 09:10 開門，之後把藍碗放到工作桌。 | 日誌記的是事件時間，無法據此知道當時有沒有拍攝。 |
| S2 | 交件清單有兩段。K1 拍到燒製前關窯門，K2 拍到工作桌上的藍碗。這批交件缺開門畫面。 | 清單只涵蓋這批交件，桌上的成品無法補證開門畫面。 |
| P1 | 剪接助理在成品先出現的版本提議，在藍碗畫面加上「出窯」字卡。 | 字卡仍待導演決定。 |

## 可獨立發出的稿件

### A

> 先看窯門關上，這是 K1 拍到的畫面。日誌寫著隔天 09:10 開門，這一拍在交件裡仍缺畫面。接著看工作桌上的藍碗，這是 K2 拍到的成品。

### B

> 先看工作桌上的藍碗，這是 K2 拍到的成品。再回看窯門關上，這是 K1 拍到的畫面。日誌寫著隔天 09:10 開門，這一拍在交件裡仍缺畫面。建議在藍碗畫面加上「出窯」字卡，請導演決定。

### C

> 目前缺少窯門打開那一刻的畫面。請先查有沒有其他已拍素材可補。若找不到，再交導演決定是否需要補拍。

## 兩張修改卡

每次從原始三稿開始，發一張卡，收回 A、B、C 三份全文。

- **R1**　陶工核對後把日誌的開門時間更正為 09:20。交件清單相同。
- **R2**　剪接助理撤回「出窯」字卡提案，導演仍希望在這一版先看成品。

## 主持人判讀

先交 A 或 B 的引文內文，使用中性檔名。先問「你第一個想到哪個畫面？哪一句讓你這樣想？」收回答後，再問「你手上有哪些畫面可以剪？作決定前，你還會向製片確認什麼？」A 預期先指出關門，B 預期先指出桌上的藍碗。另記讀者能否指出缺的是開門畫面。把碗當成已拍到開門，或把缺鏡解讀為當天沒有開門，都要留下原話。兩版另有字卡提案差異，單獨測順序時需先對齊這項安排。

核對來源時，A 引用 S1、S2，B 引用 S1、S2、P1，C 引用 S2。

| 卡 | 應改 | 應保留 |
| --- | --- | --- |
| R1 | A、B 的日誌時間改為 09:20。 | C 原樣交回。K1、K2 仍只涵蓋原清單的畫面。 |
| R2 | 只刪 B 的字卡提案。 | B 仍先見藍碗，A、C 原樣交回。補拍仍待決定。 |

分別記第一焦點、缺鏡判讀、漏改稿號及連帶改壞的句子。此案未列入既有計分器的答案表。主持人依上表核對。
