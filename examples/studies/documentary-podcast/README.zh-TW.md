# 渡口的聲音

[English](README.md) · [情境總覽](../../README.zh-TW.md)

## 受眾與作者請求

沒去過這個渡口的地方史節目聽眾。

為同一段紀實節目寫兩款開場。一款先讓受訪者說話，另一款讓旁白先交代背景。另交給錄音師一張補錄單。保留逐字引語，清楚區分剪點與現有聲音。

## 素材卡

| ID | 材料 |
| --- | --- |
| S1 | 合成訪談逐字稿，00:21–00:26。前渡船工作人員說：「繩子濕了。就這樣從我的手套上滑過去。」此練習提供的是逐字稿。 |
| S2 | 製作筆記：訪談在這位前渡船工作人員的家中進行，主題是渡口的繩門。沒有提供在渡口錄下的環境音。 |
| P1 | 以到府訪談背景開場的版本，製作人提議在受訪者開口前留兩秒空白。 |

### 稿件 C

旁白補錄，乾聲：「我們到這位前渡船工作人員的家裡，請他談談渡口的繩門。」單錄人聲。目前沒有從渡口帶回的環境音。

## 給接手者的修改卡

一次只發一張卡。從原始 A、B、C 三稿開始，交回三份可供比對的改後稿，包含原樣交回的版本。請記下待確認的推論或使用條件。

### R1

逐字稿編輯更正引語位置為 00:24–00:29。核定的引語逐字保留。

### R2

製作人撤回兩秒停頓的提議。下一拍就讓受訪者接話，不做定時留白。
