# 兩張椅子之間的一碗湯

[English](README.md) · [情境總覽](../../README.zh-TW.md)

## 受眾與作者請求

家族聚餐上聽約 45 秒口述的親友。讀者先不看原照片，以相同語速聽兩個版本。

以一張合成老照片與講述者的回憶，為同一場家族聚餐寫兩版約 45 秒的口述。一版可從看得見的動作開始，另一版先談它後來帶給人的感受。沒有逐字紀錄的事請轉述，另外給投影片操作員一張獨立提示單。

## 素材卡

| ID | 材料 |
| --- | --- |
| S1 | 照片標註攝於 1996 年。兩張木椅之間，阿姨把白色湯碗遞給年輕晚輩，兩個人的手都還搭在碗沿。照片只記下當下那一刻。 |
| S2 | 當年接碗的晚輩就是現在的講述者。他記得自己晚到，擔心打斷聚餐，接到湯時覺得家人迎他入座。沒有人留有錄音，也沒有人記得原話。 |
| P1 | 投影版本提議先裁出交接時的手部特寫，再拉開看到兩張椅子。這是放映手法。 |

### 稿件 C

放映提示｜先帶到白色湯碗旁兩人交接的手，再慢慢拉開，讓兩張木椅一起入鏡。講述者說完前，畫面留在照片上。

## 給接手者的修改卡

一次只發一張卡。從原始 A、B、C 三稿開始，交回三份可供比對的改後稿，包含原樣交回的版本。請記下待確認的推論或使用條件。

### R1

講述者更正記憶：當天其實提早到了，擔心家人還在準備聚餐，自己進去會礙手礙腳。接到湯後感到被歡迎的記憶仍保留。

### R2

親友希望致詞時從頭到尾都看完整的靜態照片，決定取消裁切和拉遠。
