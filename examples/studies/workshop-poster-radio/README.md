# An invitation to mend an umbrella

[繁體中文](README.zh-TW.md) · [All cases](../../README.md)

## Audience and author request

Neighbors who have never attended the umbrella repair session.

Use the workshop notice, schematic, and sound description. Write two short radio invitations to the same neighbors. Start one with the invitation and the other with the taps. Give the illustrator a poster brief. Keep the files distinct and leave the time and venue open.

## Source cards

| ID | Material |
| --- | --- |
| S1 | Workshop notice: Saturday is the umbrella repair session. Bring one umbrella. No clock time, venue, or repair guarantee is given. |
| S2 | Workbench schematic (bench.svg). The folded blue umbrella is on the left. A spool of ochre thread is on the right. |
| S3 | Separate audio file (taps.wav). Two synthetic taps occur about 0.20 and 0.75 seconds into the 1.08-second recording. It contains no speech and does not establish what made the sounds. |
| P1 | The writer proposes the figurative line “One calls. One answers.” Only the sound-first version may use it. The words do not identify the sound source. |
