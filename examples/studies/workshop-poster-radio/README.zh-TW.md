# 邀請鄰居來修傘

[English](README.md) · [情境總覽](../../README.zh-TW.md)

## 受眾與作者請求

還沒參加過修傘工作坊的鄰居。

根據工作坊公告、工作桌示意圖與聲音說明，為同一群鄰居寫兩款廣播短稿。一款先播邀請，另一款先播敲擊聲。再交給插畫師一份海報構圖。圖檔與音檔分開標示；未提供的時間與地點留白。

## 素材卡

| ID | 材料 |
| --- | --- |
| S1 | 活動公告：週六舉辦修傘工作坊，請帶一把傘。沒有提供幾點開始、場地或修復保證。 |
| S2 | 工作桌示意圖（bench.svg）。收起的藍傘在左側，右側是纏著赭色線的線軸。 |
| S3 | 另一份素材是獨立音檔（taps.wav），長 1.08 秒，約在 0.20 秒與 0.75 秒各有一聲合成敲擊。沒有人聲，無法由此辨識敲擊物。 |
| P1 | 作者提議一句比喻：「一聲呼喚，一聲回應。」只供以聲音開場的版本使用，這句話沒有指認聲音的來源。 |

## 三份交付稿

[讀本 A](A.zh-TW.md) · [讀本 B](B.zh-TW.md)

### 稿件 C

海報構圖：收起的藍傘放左邊，纏著赭色線的線軸放右邊。邀請文字排在兩個物件之間的留白：「週六修傘工作坊。請帶一把傘。」

## 給接手者的修改卡

一次只發一張卡。從原始 A、B、C 三稿開始，交回三份可供比對的改後稿，包含原樣交回的版本。請記下待確認的推論或使用條件。

### R1

主辦方將工作坊從週六改到週日。仍請每位參加者帶一把傘。

### R2

作者收回呼喚與回應的比喻。播完兩聲敲擊，就直接進入邀請。
