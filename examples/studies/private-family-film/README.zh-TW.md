# 廚房記憶的兩個剪輯版本

[English](README.md) · [情境總覽](../../README.zh-TW.md)

## 受眾與作者請求

從未聽過這段廚房往事的家宴親友。兩份家宴旁白用相同語速朗讀；私人版提示單只交剪輯師。

用合成素材替家宴寫兩段短旁白。講同一個廚房回憶，但從不同的地方起頭；再替只有兩人看的版本寫一條剪接提示，按素材適用範圍安排聲音。

## 素材卡

| ID | 材料 |
| --- | --- |
| S1 | 家宴與兩人版都可使用的照片描述：兩雙手一起洗花椰菜，中間放著藍色瀝水籃。照片沒有聲音。 |
| S2 | 說故事的人記得，兩人一起學著把花椰菜分成小朵，晚餐從那時起成了兩人一起做的日常。這是回憶，沒有逐字紀錄。 |
| P1 | 虛構當事人只同意在兩人版播放另錄的悄悄話「最後一朵留給我」。剪輯師預留三秒播放悄悄話，接兩秒安靜定格。家宴可用照片與上述回憶。 |

## 三份交付稿

[讀本 A](A.zh-TW.md) · [讀本 B](B.zh-TW.md)

### 稿件 C

兩人版剪接提示｜照片停在藍色瀝水籃上。預留三秒播出另錄的悄悄話：「最後一朵留給我。」接著再安靜定格兩秒。

## 給接手者的修改卡

一次只發一張卡。從原始 A、B、C 三稿開始，交回三份可供比對的改後稿，包含原樣交回的版本。請記下待確認的推論或使用條件。

### R1

重新看過合成照片，確認瀝水籃是白色；請修正沿用舊描述的顏色。

### R2

兩位當事人撤回悄悄話錄音的所有用途。移除該段話及其聲軌，改成等長的安靜定格。
