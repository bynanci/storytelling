## Audience and author request

Family guests who have never seen this kitchen memory. Read the two family voice-overs aloud at the same pace; the private cue goes only to the editor.

Write two short voice-overs for the family screening. Tell the same kitchen memory with a different opening. Then give the editor a cue for a separate two-person cut using only the material cleared for that cut. Work with synthetic material.

## Source cards

| ID | Material |
| --- | --- |
| S1 | Photo description for the family screening and the two-person cut: a blue colander stands between two pairs of hands washing broccoli. There is no audio with the photo. |
| S2 | The narrator remembers that learning to break a head of broccoli into small florets together made cooking dinner feel like a shared habit. This is a recollection, not a recorded quote. |
| P1 | The fictional couple approved the separately recorded whisper “Leave me the last floret” only for the two-person cut. The editor has reserved three seconds for the whisper, then two seconds of silence. The family screening may use the photo and the recollection. |
