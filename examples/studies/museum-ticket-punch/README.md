# A ticket punch and a hole in a ticket

[繁體中文](README.zh-TW.md) · [All cases](../../README.md)

## Audience and author request

First-time visitors looking at a station display. The two readings are short audio-guide scripts.

Write two short stops for the same display. Open one at the ticket corner and one with the collection record. Give the illustrator a separate close-up brief. Attribute the date to the record and leave the maker of the hole unknown.

## Source cards

| ID | Material |
| --- | --- |
| S1 | The collection card records 1972 as the year this punch was used. It gives no date for the ticket. |
| S2 | The display photograph shows the punch jaws beside a ticket with a round hole in one corner. No note identifies the tool that made the hole. |
| P1 | Illustrator’s proposal for the close-up only: use a blue arc to guide the eye between the two shapes. |

### Draft C

Close-up for the illustrator: crop to the ticket corner and the punch jaws. Keep the round hole visible. Add a blue arc in the margin to guide the eye between the shapes. Leave a small gap at each end so the arc reads as a guide mark.

## Change cards for the next editor

Issue one card at a time. Start from fresh copies of A, B and C. Return all three for comparison, including any you kept intact. Note any inference or use condition that needs confirmation.

### R1
