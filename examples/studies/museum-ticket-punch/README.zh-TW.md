# 打票鉗與票角的圓孔

[English](README.md) · [情境總覽](../../README.zh-TW.md)

## 受眾與作者請求

第一次看車站展件的觀眾。兩段都是在同一展櫃前聆聽的短導覽。

替同一個展櫃寫兩段短導覽，一段從票角講起，另一段從館藏紀錄講起。另寫一份特寫構圖給插畫師。年代註明來自館藏卡，為圓孔留下形成原因未知的空間。

## 素材卡

| ID | 材料 |
| --- | --- |
| S1 | 館藏卡記載這把打票鉗的使用年份為 1972 年，沒有記載車票的年代。 |
| S2 | 展件照片裡，鉗口旁有一張車票，票角有個圓孔。沒有紀錄指認是哪把工具打的孔。 |
| P1 | 插畫師只為特寫提出的設計：加一條藍色弧線，把視線從一個形狀帶到另一個。 |

## 三份交付稿

[讀本 A](A.zh-TW.md) · [讀本 B](B.zh-TW.md)

### 稿件 C

給插畫師的特寫稿：畫面裁到票角與鉗口，讓圓孔完整露出。在留白處加一道藍色弧線，引導視線在兩個形狀間移動。弧線兩端各留一點空隙，讓人看得出這是導引記號。

## 給接手者的修改卡

一次只發一張卡。從原始 A、B、C 三稿開始，交回三份可供比對的改後稿，包含原樣交回的版本。請記下待確認的推論或使用條件。

### R1

典藏人員更正館藏卡，使用年代改為「約 1970 年代」，資料無法定位到單一年份。

### R2

插畫師把藍色弧線改為黑色虛線。
