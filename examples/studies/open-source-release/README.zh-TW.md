# 發版示範可以承諾什麼

[English](README.md) · [情境總覽](../../README.zh-TW.md)

## 受眾與作者請求

考慮試用虛構工具 Shelf Map 的開發者。兩稿都是發版影片的開場口播。

替發版影片寫兩段短開場，一段先示範操作，另一段先交代測試依據。另寫一張講師提示卡。平台與快捷鍵均以提供的紀錄為準。

## 素材卡

| ID | 材料 |
| --- | --- |
| S1 | 原發版驗證表列出 Linux 與 Windows 都通過範例匯入測試，未列其他受測平台。 |
| S2 | 示範專案中，按 M 會開啟範例資料夾的對照圖，點選項目會顯示原始路徑。 |
| P1 | 講師只在提示卡上提出演出安排：游標停在路徑上兩秒，讓觀眾看清文字。 |

## 三份交付稿

[讀本 A](A.zh-TW.md) · [讀本 B](B.zh-TW.md)

### 稿件 C

講師提示卡：按 M 打開範例資料夾的對照圖，點選一個項目。游標在原始路徑停兩秒，再繼續往下講。

## 給接手者的修改卡

一次只發一張卡。從原始 A、B、C 三稿開始，交回三份可供比對的改後稿，包含原樣交回的版本。請記下待確認的推論或使用條件。

### R1

維護者發現 Windows 的 CI 只完成編譯。實際操作並通過範例匯入的是 Linux。分開敘述兩種驗證結果。

### R2

講師把停留時間由兩秒改為四秒。
