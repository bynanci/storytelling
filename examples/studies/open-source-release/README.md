# What a release demo can promise

[繁體中文](README.zh-TW.md) · [All cases](../../README.md)

## Audience and author request

Developers deciding whether to try a fictional tool called Shelf Map. A and B are short release-video openings.

Give release-video viewers two short openings. In one, demonstrate an action first; in the other, begin with the test evidence. Prepare a separate presenter card. Use only the named platforms and the documented shortcut.

## Source cards

| ID | Material |
| --- | --- |
| S1 | The initial release ledger lists successful sample import on Linux and Windows. It lists no other tested platforms. |
| S2 | In the supplied demo project the shortcut M opens a map of the sample folder. Selecting an entry reveals its original path. |
| P1 | For the presenter card, the speaker proposes holding the pointer on the path for two seconds so the audience can read it. |

Presenter card: open the sample folder map with M. Select an entry. Hold the pointer on its original path for two seconds before moving on.
