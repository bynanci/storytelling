# 客戶會議前的用量變化

[English](README.md) · [情境總覽](../../README.zh-TW.md)

## 受眾與作者請求

參加季度回顧的客戶營運主管。兩稿都是會議開場口述。

為同一場回顧會議寫兩種開場，一次先報數字，一次先談客戶的問題。再給帳務分析人員一份追蹤便箋，清楚交代哪些已量測、哪些有待核對。

## 素材卡

| ID | 材料 |
| --- | --- |
| S1 | A 服務前四週用量為 10,000 分鐘，後四週為 8,800 分鐘，減少 12%。報表沒有解釋原因。 |
| S2 | 前次會議中，客戶提到兩處據點搬遷，並詢問帳單是否涵蓋兩處。搬遷日期與用量間的因果關係均未確認。 |
| P1 | 業務只在以提問開場的版本建議下一步把搬遷日期標在用量圖上。 |

## 三份交付稿

[讀本 A](A.zh-TW.md) · [讀本 B](B.zh-TW.md)

### 稿件 C

給帳務分析人員：請找出客戶提到的兩處搬遷據點各對應哪筆計費紀錄。若有據點未列入，記下是哪一處。解讀紀錄前，再向客戶確認搬遷日期。

## 給接手者的修改卡

一次只發一張卡。從原始 A、B、C 三稿開始，交回三份可供比對的改後稿，包含原樣交回的版本。請記下待確認的推論或使用條件。

### R1

帳務調整將後四週用量更正為 9,200 分鐘。前四週數字維持原值，連帶更正衍生百分比。

### R2

業務希望下一步改為逐點核對帳單，取代在圖上標日期的做法。
