# A usage figure before a customer meeting

[繁體中文](README.zh-TW.md) · [All cases](../../README.md)

## Audience and author request

The customer’s operations lead at a quarterly review. A and B are spoken openings.

Open the same review in two ways. Start with the measured change once and the customer’s open question once. Prepare a separate follow-up note for the account analyst. Keep cause and measurement separate.

## Source cards

| ID | Material |
| --- | --- |
| S1 | Service A was used for 10,000 minutes in the first four-week period and 8,800 in the next. The decrease is 12%. The report gives no cause. |
| S2 | In the previous meeting the customer reported two site moves and asked whether both sites were included in billing. Neither the move dates nor a causal link were confirmed. |
| P1 | For the question-led opening only, the account manager proposes plotting the move dates on the usage chart as a next step. |

## Three deliverables

[Excerpt A](A.md) · [Excerpt B](B.md)

### Draft C

For the account analyst: identify the billing entries for the two sites the customer said had moved. If a site is absent, record which one. Ask the customer to confirm the move dates before interpreting either entry.

## Change cards for the next editor

Issue one card at a time. Start from fresh copies of A, B and C. Return all three for comparison, including any you kept intact. Note any inference or use condition that needs confirmation.

### R1

A billing adjustment corrects the second period to 9,200 minutes. The first period is unchanged. Update any derived percentage.

### R2

The account manager prefers a site-by-site billing comparison to plotting dates. Replace the proposed next step.
