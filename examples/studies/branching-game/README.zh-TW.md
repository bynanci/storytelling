# 渡口的牌子

[English](README.md) · [情境總覽](../../README.zh-TW.md)

## 受眾與作者請求

第一次玩到渡口這一幕的玩家。逐段顯示文字，兩版開始前，玩家掌握的資訊相同。

依世界設定寫兩版三拍的可玩文字場景。兩條路線發生相同事件、走到同一個結尾；改變玩家得知瑪拉動機的時機。伊沃只能知道他親眼看過的事。另外交給任務編輯一張可送交 QA 的場景卡。

## 素材卡

| ID | 材料 |
| --- | --- |
| S1 | 第一聲鐘響，瑪拉把渡口掛鉤上的黃銅牌收進袖裡。伊沃趕到、摸到空鉤，喊渡口管理員。 |
| S2 | 瑪拉的摺紙條寫著：「我借了牌子，好送爸爸過河。我會還的。」伊沃到第二聲鐘響才打開。玩家可以比他先看到紙條。手指停在「爸爸」兩個字上。 |
| P1 | 僅在提前揭露的版本，將紙條以特寫小窗疊在碼頭畫面上。這是畫面設計提議。 |

給玩家逐拍閱讀。先記下玩家此刻認為角色知道什麼，再出示下一拍。

## 三份交付稿

[讀本 A](A.zh-TW.md) · [讀本 B](B.zh-TW.md)

### 稿件 C

任務 QA 交接｜第二聲鐘響、伊沃拆開紙條以前，請讓他的對話保留瑪拉借牌子的原因。等他讀到「爸爸」，台詞才可以提這趟渡河是為了誰。

## 給接手者的修改卡

一次只發一張卡。從原始 A、B、C 三稿開始，交回三份可供比對的改後稿，包含原樣交回的版本。請記下待確認的推論或使用條件。

### R1

道具美術更正牌子的材質為銀。第一聲鐘響時的反光要符合新材質。紙條仍只稱它為「牌子」。

### R2

提前出現的紙條改用全幅黑底字卡。移除特寫小窗，保留紙條文字與出現時機。
