# 摺進節目單裡的鑰匙

[English](README.md) · [情境總覽](../../README.zh-TW.md)

## 受眾與作者請求

閱讀一齣後台短劇的讀者。

把同一個虛構的後台場景寫成兩款開場。一版讓觀眾先看到鑰匙藏在哪裡，再讓任遇到難題；另一版在難題出現後才揭露藏處。維持相同的事件與發生次序，另給場記一張保留未決分支的接戲卡。

## 素材卡

| ID | 材料 |
| --- | --- |
| S1 | 虛構情節：開演鈴響前，瑪拉在側門把一把備用黃銅鑰匙摺進節目單。 |
| S2 | 開演鈴響時，任從側門玻璃看見喬帶著小提琴抵達。序曲響起，任伸手探向摺好的節目單，要決定為喬開門，或等序曲演奏完才開門。目前兩種結局都保留。 |
| P1 | 導演希望在一開場就拍瑪拉藏鑰匙的特寫上，加一圈鉛筆線框住鑰匙。這是順敘版的圖像疊層，節目單上沒有畫圈。 |

## 三份交付稿

[讀本 A](A.zh-TW.md) · [讀本 B](B.zh-TW.md)

### 稿件 C

接戲卡：鈴響前，瑪拉在側門把黃銅鑰匙摺進節目單。鈴響時，喬帶著小提琴抵達。兩版都保留任的最後選擇：現在開門讓喬進來，或關著門等序曲演奏完。

## 給接手者的修改卡

一次只發一張卡。從原始 A、B、C 三稿開始，交回三份可供比對的改後稿，包含原樣交回的版本。請記下待確認的推論或使用條件。

### R1

道具組把備用鑰匙的材質從黃銅改為鐵。藏處和瑪拉放鑰匙的時點照舊。

### R2

取消鉛筆線圈的疊圖。特寫照拍，讓觀眾直接看見藏鑰匙的動作。
