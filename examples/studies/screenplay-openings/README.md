# The key in the folded program

[繁體中文](README.zh-TW.md) · [All cases](../../README.md)

## Audience and author request

Readers of a short backstage drama.

Open the same fictional backstage scene twice. In one opening let the audience see where the key went before Ren needs it. In the other, reveal the hiding place after the dilemma. Keep what happened and when consistent. Give the continuity editor a short card preserving the choice that is still open.

## Source cards

| ID | Material |
| --- | --- |
| S1 | Fictional event before the house bell. Mara places the spare key inside a folded program at the side door. The key is brass. |
| S2 | At the bell, Jo arrives with a violin and can be seen through the side-door window. As the overture starts, Ren reaches toward the folded program. Ren must decide whether to open the door for Jo or keep it shut through the overture. Neither ending has been selected. |
| P1 | The director requests a pencil circle around the key in the opening insert that shows Mara placing it. It is a graphic overlay for the chronological cut, not a mark on the physical program. |

### Draft C

Continuity card. Before the bell, Mara folds the brass key inside the program at the side door. At the bell, Jo arrives with the violin. Leave the last action open for both cuts: Ren can let Jo in or hold the door shut through the overture.

## Change cards for the next editor

Issue one card at a time. Start from fresh copies of A, B and C. Return all three for comparison, including any you kept intact. Note any inference or use condition that needs confirmation.

### R1

Props changed the spare key from brass to iron. The hiding place and the moment Mara leaves it stay the same.

### R2

Remove the proposed pencil-circle overlay. Show the action in the insert without a graphic.
