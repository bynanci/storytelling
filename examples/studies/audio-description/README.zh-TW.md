# 椅子與手套

[English](README.md) · [情境總覽](../../README.zh-TW.md)

## 受眾與作者請求

無畫面、透過口述影像聽這一幕的觀眾。這份文字原型先由同一人以相同語速朗讀兩版。

替同一段舞台演出寫兩版可朗讀的口述影像腳本。一版先說方位，另一版先說動作；使用指定的兩個空檔，保留詮釋角色動機的空間。另交錄音師一張提示單。

## 素材卡

| ID | 材料 |
| --- | --- |
| S1 | 開場時椅子在觀眾看去的左側。一名女子把紅手套放在椅面。00:08，她把空著的手掌轉向觀眾。 |
| S2 | 可口述的空檔為 00:00–00:06 和 00:08–00:14。角色在 00:06–00:08 說「等等」，該段留給台詞。 |
| P1 | 在以方位開場的版本，提議報完椅子位置後停半秒。請把停頓算入前六秒的空檔，試讀時計時確認。以動作開場的版本採連貫朗讀。 |

## 三份交付稿

[讀本 A](A.zh-TW.md) · [讀本 B](B.zh-TW.md)

### 稿件 C

錄音交接｜00:00 起第一段口述，00:06 前收聲。00:06–00:08 留給「等等」。00:08 接第二段口述，最晚 00:14 結束。

## 給接手者的修改卡

一次只發一張卡。從原始 A、B、C 三稿開始，交回三份可供比對的改後稿，包含原樣交回的版本。請記下待確認的推論或使用條件。

### R1

舞監更正椅子方位：由觀眾看去，在右側。時點維持原樣。

### R2

配音導演決定取消半秒停頓。請在原空檔裡連著唸完。
