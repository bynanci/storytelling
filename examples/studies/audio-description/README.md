# The chair and the glove

[繁體中文](README.zh-TW.md) · [All cases](../../README.md)

## Audience and author request

Listeners following an audio description of the same stage scene without its picture. For this text prototype, one person reads both scripts at the same pace.

Prepare two speakable description scripts for the same performance excerpt. Introduce the scene from its spatial anchor in one and from the actor's movement in the other. Use the two speech windows. Give the recording engineer a third cue card. Keep the actor's motives open.

## Source cards

| ID | Material |
| --- | --- |
| S1 | At the start, a chair stands on the audience’s left. A woman sets a red glove on its seat. At 00:08 she turns her empty palm toward the audience. |
| S2 | The description windows are 00:00–00:06 and 00:08–00:14. The character speaks “Wait” between 00:06 and 00:08. Keep that interval clear. |
| P1 | The spatial opening has one proposed half-second pause after it locates the chair. Budget the pause inside the first six-second window and check its fit in the read-through. The action opening runs without that pause. |
