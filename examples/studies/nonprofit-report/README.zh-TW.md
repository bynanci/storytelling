# 一位參與者的話與一場活動的人數

[English](README.md) · [情境總覽](../../README.zh-TW.md)

## 受眾與作者請求

閱讀社區工作小組近況的捐助者。

用一段經確認的引語和簽到表寫兩則給捐助者的短訊，一則從當事人開始，一則從簽到數字開始。另給志工帶隊人一份交接說明，交代證言及簽到數字各能說明什麼。

## 素材卡

| ID | 材料 |
| --- | --- |
| S1 | 兩次活動的簽到表合計 18 人次，沒有不重複人數、信心變化或回訪人數。 |
| S2 | 一位參與者同意匿名在捐助者近況短訊使用原話：「第一次女兒陪我來，下一次我自己來了。」 |
| P1 | 編輯只在以簽到數字開場的版本提議收尾時邀請讀者寄一個問題給工作小組。 |

## 三份交付稿

[讀本 A](A.zh-TW.md) · [讀本 B](B.zh-TW.md)

### 稿件 C

給志工帶隊人：出席摘要請寫「兩次活動共 18 人次簽到」。日後若要回報實際參加人數或回訪比率，需另外記錄不重複人數，讓同一人的多次出席可以辨認。

## 給接手者的修改卡

一次只發一張卡。從原始 A、B、C 三稿開始，交回三份可供比對的改後稿，包含原樣交回的版本。請記下待確認的推論或使用條件。

### R1

當事人撤回近況短訊的使用同意。給捐助者的材料須移除原話與能辨識這段個人經驗的轉述。

### R2

把「寄來一個問題」的邀請改為開放讀者來信詢問下次活動日期。
