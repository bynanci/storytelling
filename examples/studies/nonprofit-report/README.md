## Audience and author request

Community donors reading a short update about a fictional neighborhood group.

Write two short donor updates using one approved excerpt and the sign-in sheet. Begin with the person in one version and the count in the other. Give the volunteer coordinator a handoff note. Keep the person’s experience distinct from what the count establishes.

## Source cards

| ID | Material |
| --- | --- |
| S1 | The sheet records 18 check-ins over two sessions. It does not record unique people, changes in confidence, or how many returned. |
| S2 | A participant approved this quotation for the donor update: “My daughter came with me the first time. The next time I came on my own.” The participant asked to remain unnamed. |
| P1 | For the count-led update only, the editor proposes ending with an invitation to send a question to the group. |

## Three deliverables

### Draft C

Volunteer coordinator: copy the total as “18 check-ins across two sessions” when preparing the attendance note. To report a head count or return rate, collect a separate count that distinguishes people from visits.

## Change cards for the next editor

Issue one card at a time. Start from fresh copies of A, B and C. Return all three for comparison, including any you kept intact. Note any inference or use condition that needs confirmation.

### R1

### R2
