# What changed before the import?

[繁體中文](README.zh-TW.md) · [All cases](../../README.md)

## Audience and author request

Teams evaluating a spreadsheet import preview.

Write two short announcements for the same team about the import preview. Let one open with the task and one with the trial result. Keep the sample and measurement visible. Give the salesperson a short talk track for a customer call. Separate trial observations from promises.

## Source cards

| ID | Material |
| --- | --- |
| S1 | Four volunteers each imported the same six-row sheet with both versions. The median completion time was ten minutes with the old version and eight with the preview. No other sheets or teams were timed. |
| S2 | The preview highlights unmatched column headers before import. Selecting Review mapping lets the user inspect those headers. |
| P1 | The salesperson may close by inviting the customer to bring a sample sheet to the next call. This is a meeting proposal. |
