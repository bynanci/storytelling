# 匯入前多了哪一步？

[English](README.md) · [情境總覽](../../README.zh-TW.md)

## 受眾與作者請求

評估試算表匯入預覽功能的團隊。

為同一個團隊寫兩則匯入預覽公告。一則先說使用者能做什麼，另一則先說試行結果。交代樣本與計量方式，再替業務寫一段客戶電話口述。試行觀察與對客戶的承諾要分清楚。

## 素材卡

| ID | 材料 |
| --- | --- |
| S1 | 四位志願者各用新舊版本匯入同一份六列試算表。完成時間中位數為舊版十分鐘、預覽版八分鐘。沒有為其他表格或團隊計時。 |
| S2 | 匯入前的預覽會標出尚未配對的欄名。選取「檢視對應」可以逐項查看。 |
| P1 | 業務可在結尾邀請客戶下次通話帶一份樣本表格。這是會議安排。 |

## 三份交付稿

[讀本 A](A.zh-TW.md) · [讀本 B](B.zh-TW.md)

### 稿件 C

「匯入前就能看到哪些欄名還沒配對。我們請四個人用新舊版本匯入同一份六列試算表，完成時間中位數從十分鐘降到八分鐘。跟你們平常的做法差多少？下次通話帶一份樣本表格，我們一起看看。」

## 給接手者的修改卡

一次只發一張卡。從原始 A、B、C 三稿開始，交回三份可供比對的改後稿，包含原樣交回的版本。請記下待確認的推論或使用條件。

### R1

試行紀錄更正：預覽版完成時間中位數為九分鐘。舊版中位數與試行設計維持原紀錄。

### R2

下次通話改用預先備好的示範檔，不再邀請客戶帶樣本表格。
