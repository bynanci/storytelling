# 地方版本的口袋地圖

[English](README.md) · [情境總覽](../../README.zh-TW.md)

## 受眾與作者請求

出發前在 App 內看提示卡的通勤乘客。一次測一種語言，找平常使用該語言的讀者。

替同一群乘客寫兩張旅遊 App 提示卡。兩版都要說清離線期限與修改條件，一版先講規則，一版用通過審稿的在地意象帶入。另交客服一段各地都可以用的直接回覆。

## 素材卡

| ID | 材料 |
| --- | --- |
| S1 | 先前儲存的路線圖，在最近一次成功同步後的 48 小時內可以離線開啟。 |
| S2 | 修改已儲存的路線需要網路連線。 |
| P1 | 只有以意象開頭的地方版獲准用「外套口袋裡的地圖」這個比喻。它用來說明如何取用，App 不會製作紙本地圖。 |

## 三份交付稿

[讀本 A](A.zh-TW.md) · [讀本 B](B.zh-TW.md)

### 稿件 C

客服回覆｜已儲存的路線圖最近一次同步成功後，48 小時內可離線開啟。如需編輯這條路線，請先連上網路。

## 給接手者的修改卡

一次只發一張卡。從原始 A、B、C 三稿開始，交回三份可供比對的改後稿，包含原樣交回的版本。請記下待確認的推論或使用條件。

### R1

已確認離線期限從最近一次成功同步後的 48 小時縮為 24 小時。

### R2

地方主編將外套口袋的意象改為「背包裡摺好的地圖」。這次只換比喻。
