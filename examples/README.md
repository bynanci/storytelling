# Storytelling examples

English · [繁體中文](README.zh-TW.md)

Start with [the museum ticket punch](studies/museum-ticket-punch/README.md). Give a reader an unlabeled A or B excerpt. Give a different editor three drafts and one correction. Follow the [reading and revision protocol](evaluation/README.md) to collect observations. These are synthetic practice cases; the facilitator records actual outcomes separately.

Within each case, A and B address the same audience in the same language. C is a third handoff artifact. The author page has the request, sources, drafts and two change cards. Give readers only the excerpt body. The facilitator keeps the source maps and marking keys separately.
