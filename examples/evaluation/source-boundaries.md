# What each source supports

English · [繁體中文](source-boundaries.zh-TW.md) · [Study protocol](README.md)

For the `mapped-bounds` condition, give the next editor the ordinary three-row source map and the table for the assigned case below. Each table describes the starting sources. Apply the current change card to its source and carry forward the limits that still hold. The `mapped` condition uses the ordinary source map alone. Keep these tables with the handoff materials, away from the blind readings.

<a name="museum-ticket-punch"></a>

## A ticket punch and a hole in a ticket

| Source | Supported use | Evidence limit or permitted scope |
| --- | --- | --- |
| S1 | The collection card dates the use of this punch. | The date applies to the punch. The ticket's date is unknown. |
| S2 | The photograph places the jaws beside a ticket with a round hole. | The photograph gives no evidence that this tool made that hole. |
| P1 | The illustrator proposes a guide mark between the shapes in the close-up. | Treat the mark as part of the composition. Its appearance supplies no evidence about either object. |

| Source | Supported use | Evidence limit or permitted scope |
| --- | --- | --- |
| S1 | The stage notes give the chair's position from the audience, the red glove on its seat and the empty palm turned at 00:08. | Describe visible actions from the stated viewpoint. The performer's intentions are unspecified. |
| S2 | The script has description windows at 00:00–00:06 and 00:08–00:14. Dialogue occupies the interval between them. | Keep the dialogue audible. The windows alone cannot establish that a spoken take fits. |
