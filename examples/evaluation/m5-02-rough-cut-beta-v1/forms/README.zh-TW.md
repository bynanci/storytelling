# 空白主持人表單

這些檔案只有標題列／範本。收集資料前請複製至有存取控管的私人儲存位置。不可在本儲存庫填寫。

- `participants.csv`：每個分派名額一列；不可加入姓名或聯絡方式。
- `allocation.csv`：預定與實際條件／素材包順序；試用結束前保留分派種子。
- `sessions.csv`：每位參與者、每種條件一列；逾時記 2,700 秒且未完成。
- `scorecard.csv`：每項需求、每組一列；分開記漏改、誤改、多改／連帶修改及重工。
- `process-events.csv`：逐次工具／宿主處理時間，與作者工時分開。
- `ratings.csv`：每個問題、每組一列；未經同意不可引用原話。
- `follow-up.csv`：每位參與者一列；分開記錄回訪邀請／回覆，以及第 14–28 天在 S 實際安全完成第二個專案的結果。意願不等於實際回流。
- `failures.csv`：詳細私人失敗紀錄 `failure-record.md` 的索引。
- `deviations.csv`：保留預定與實際程序的差異。
- `pack-freeze.csv`：每項素材與來源卡一列；使用精確有理數區間、中性 ID、SHA-256，不記本機路徑。
- `freeze-receipts.csv`：每包一列，包含清單、起始專案、來源卡、答案鍵及建置雜湊。
- `summary.csv`：附分母報計數；未知不可當成零。

規程定義計算方式與決策門檻。CSV 本身不能證明來源事實、參與者身分或人工核准。
