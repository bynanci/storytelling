# 驗證觀眾讀法與接手改稿

[English](README.md) · 繁體中文 · [挑選案例](../README.zh-TW.md)

安排一位主持人、符合設定的讀者，以及一位沒寫過原稿的接手編輯。兩個練習可以分開做。所有案例皆使用合成素材。兩份 CSV 只含欄名；請使用匿名代碼，將填寫後的表單及實際改稿保存在公開儲存庫以外。

## 一、觀眾讀出了作者安排的差異嗎？

1. 固定一個情境、一種語言。作者或主持人先看[評分對照](keys.zh-TW.md)，寫定 A、B 各版的第一焦點或揭露時機，以及可接受的具體線索。如果要測自己實際生成的稿件，先換成該稿的文字、來源表與經另一位編輯確認的答案。
2. 各自複製兩份讀本的**內文**，另存為中性名稱。給讀者的畫面不包含檔名、GitHub 導覽、作者請求、素材卡、C 稿與答案。試聽兩段腳本時，固定同一讀稿者及設備。若交付物是構圖說明，可請插畫師試讀；要評估觀眾看見什麼，請先依兩份構圖製作圖像，再給觀眾看。記錄實際媒介與中性的產物版號，例如 `clip-04-v2`。把當次使用的圖、稿或錄音保存在私人試用紀錄，以便另一位評分者核對線索。
3. 一半讀者先看一版，另一半反過來。兩組維持相同受眾、語言及媒介。先收下第一份回答，再揭露另一版。請問：「你第一個注意到什麼？讀到哪裡時，你對前面的理解改變了？是哪個詞、聲音或細節讓你這樣想？如果要說給朋友聽，你會怎麼說？」逐字留下最初回答。提問時避開作者預設的差異。
4. 給第二版，重問同一組問題，最後才問兩版的差別。在[盲讀紀錄表](readings.csv)為每次接觸各記一列。在第二次接觸的 **comparison_after_both** 欄逐字記錄讀者比較兩版的說法。第一次接觸時此欄留白。初次接觸的回答另行統計。
5. 以作者事先寫定的線索判讀。讀者自行說出預期焦點或揭露時機，且能指出稿內依據，記 **match**。方向接近但缺乏依據，或同時讀到互相衝突的重點，記 **partial**。讀出其他焦點記 **different**。無法判讀記 **unknown**。保留出乎意料的讀法；有爭議時請第二位評分者複核。

A、B 各自回報「符合人數／首次接觸人數」，各留一個匿名線索或反例。探索性試用可先安排每版五個首次接觸，以兩組各至少四人讀出預定差異為預設觀察門檻，招募前先固定。若只有一版成立，先改開場、提示時機或構圖，再找新讀者重測。「比較喜歡哪版」可另外詢問。 若一組稿同時改了順序與停頓，結果只能用來評估整體寫法。想知道影響是否單獨來自順序，請先對齊其餘提示，再固定新一輪的答案。

## 二、接手者少漏改、少誤改了嗎？

1. 交付同一案的素材卡、A／B／C 三稿及**一張**修改卡，請接手者交回三份實際改後稿。保留原稿。接手者決定沿用的稿件也要原樣交回。R1 與 R2 各自從乾淨副本開始。
2. **notes** 條件提供相同材料，接手者可用一般筆記。**mapped** 額外提供評分對照中的三列「來源對照」，只複製那張表。兩組都不給答案、預期稿號及另一組改稿，維持相同工具、時限與指示。這項比較測的是現成來源表的效益。若要評估整段 Skill 流程，另計起草與製表時間並沿用[原作者試用規程](../../docs/narrative/N-01-AUTHOR-STUDY.zh-TW.md)。
3. 選擇難度接近的案例與修改卡，交換分派以降低記憶效應。例如甲編輯在 X 案用普通筆記、Y 案用來源表；乙編輯在 Y 案用普通筆記、X 案用來源表。操作條件的先後也要對調。每次記錄案例、條件、語言、秒數與有無完成。兩組時限相同，超時仍計入分母。不同媒介、語言與不平衡的題組分開報告。
4. 在 **received** 填入實際交回且可核對的稿號。缺交稿件的內容無法判定。只有收齊三稿且編輯表示已完成時，才填 **finished=yes**。逐份比對前後稿，發生實質修改記在 **changed**；完成該稿指定更正才記 **corrected**。若同時改壞應保留的事實、歸因、私密範圍或揭露順序，即使主要更正正確，也把該稿記在 **collateral**。單純順句不算誤改。留下有疑義的原句與改句，交另一位評分者複核。
5. 複製[改稿紀錄表](revisions.csv)。稿號用半形空格分開，例如 `A C`；沒有稿號時留白。語言填 `en` 或 `zh-TW`，條件填 `notes` 或 `mapped`，完成欄填 `yes` 或 `no`。將私人紀錄存在儲存庫外，在專案根目錄執行：

```sh
python3 examples/evaluation/score_revisions.py /path/to/revisions.csv
```

計分器適用於原案例與原案的[預期稿號](expected.csv)。若使用新產出的作品，請在試用前固定產物版號、來源表與經獨立複核的答案，另依該份私人答案評分。

**missed** 是應改卻未交付正確更正的稿，包含應改而缺交的稿件。**unnecessary** 是實際收到、原應保留卻遭實質更動的稿。**damaged** 是主持人判定有內容遭連帶改壞的已交回稿件，即使該稿也正確完成主要更正仍可列入。同一稿可能同時出現在兩欄，請分開統計。**unreturned** 列出無法檢視內容的缺交稿號。**exact** 須已完成，且無漏改、額外修改或連帶損害。

各條件先報不重複的編輯人數，再報完成次數／嘗試次數、完全正確次數／嘗試次數、漏改稿數／應改稿數、額外修改稿數／已交回且原應保留稿數、連帶改壞稿數／已交回稿數，以及缺交稿數／應交稿數（每次三稿）。計分器列出各次適用稿號。將可比較的嘗試加總分子與分母；分母為零時記「不適用」。R1 與 R2 難度不同時請分開。完成者的耗時報中位數，同時列出逾時及中途退出次數。用配對資料比較；若漏改減少但誤改增加，一併報告。區分前置整理與接手改稿的時間。[N-01 的既有決策門檻](../../docs/narrative/N-01-AUTHOR-STUDY.zh-TW.md)用於其原始試驗。

## 其他可能遇到的狀況

| 狀況 | 如何處理與紀錄 |
| --- | --- |
| 素材缺件、兩份證言互相衝突，或使用範圍改變 | 請接手者標出受影響處，保留可用部分，將待決事項交回作者。間接轉述可能未出現在直接引用表，另行人工複查。 |
| 有吸引力的細節缺乏來源 | 在允許的版本標為創作提議、刪去，或請作者決定。檢查它是否流入事實敘述。 |
| 想驗收配音、畫面或剪輯，手上只有文字 | 記錄這次試的是腳本或構圖。要驗收聽感與觀看效果，須交付可播放或可開啟的作品。 |
| 兩版都被讀成同樣的重點 | 保留歧異或相同的回答，一次只改第一個線索、停頓或焦點，再找新讀者試。 |
| 讀者沒看完兩版，或接手者改到一半就超時 | 保留首次接觸及已交回的結果，在分母與未完成欄一併呈現。 |
