# 敘事情境與可試用稿件

[English](README.md) · 繁體中文

先從[打票鉗](studies/museum-ticket-punch/README.zh-TW.md)開始。給讀者一份不標示作者意圖的 A 或 B 讀本；給另一位編輯三稿與一張修改卡。首次使用請參照[盲讀、交接與計分](evaluation/README.zh-TW.md)。素材與改稿題皆為合成案例，實測紀錄由主持人另填。

每案使用同一受眾、同一語言的 A／B 讀本；C 是第三份供交接的稿件。作者頁含請求、素材、稿件與兩張修改卡。讀者只收到一份讀本內文。來源表和逐稿答案獨立放在主持人手冊。
