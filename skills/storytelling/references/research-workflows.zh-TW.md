# 研究導向工作流程

[English](research-workflows.md) · 繁體中文 · [規則](editorial-rules.zh-TW.md) · [證據](research-foundations.zh-TW.md)

這六個流程是既有 `storytelling` 技能的能力，不是六個分別安裝的技能，也不引入新工具。只載入相關章節。短稿使用 W1 與適用來源檢查即可，不強制附研究報告。所有流程沿用主技能的修補額度。

## W1 · 確認意圖與來源

**觸發：**筆記或混合素材需要初稿。**輸入：**受眾、目的、語言、形式、素材與限制。非必要資料缺漏時，寫明合理假設；素材與設定都沒有時，才詢問其中一項。

1. 說明希望受眾理解或注意什麼，不承諾特定感受。
2. 列出必要來源與存取方式。需要重用或修訂時才給穩定 ID。
3. 分開提供細節、詮釋、虛構設定與單版創作。保留矛盾。
4. 先交付指定初稿，再附簡短來源說明。

**輸出：**草稿、簡要意圖／來源對照與缺項。**停止：**可用稿已存在，或缺必要來源；可行時仍交付有限稿。**規則：**ST-R01–ST-R03、ST-R14。**依據：**P01、P04、S01。

**試例：**照片描述為「兩人在門邊」，筆記未說誰修門。身分保持未知，不編造引言，也不聲稱看過照片。

## W2 · 設計敘事替案

**觸發：**比較開場、劇本揭露、長篇或分支點子。**輸入：**W1 素材、已確立虛構事實、鎖定事實與作者選定方式。

1. 長篇列出段落與相關目標；短篇用簡短順序。
2. 分開發生與揭露順序，標記必要線索是誰已知。
3. 寫兩個改變具名選擇的版本。腦力激盪保留未決分支。
4. 核對明確限制。手法改動時轉入 W5，檢查疊層或全幅替換後，必要環境背景與揭露時機是否仍保留。美感選擇保持開放；依要求保留模糊或開放結局。

**輸出：**A/B 稿、不變條件與選擇說明。**停止：**兩稿可用，或限制衝突須決定。**規則：**ST-R04–ST-R06、ST-R08。**依據：**P01–P03、P06。

**試例：**角色進大廳前遺失鑰匙，觀眾稍後才得知。非線性敘事有效。聯想 A↔B 不代表執行前置條件循環。

## W3 · 跨媒體改編

**觸發：**相同素材需要口述、插畫、聲音、影片或在地化版本。**輸入：**選定素材、受眾、無障礙需求、現有媒體與平台實際能力。

1. 列出跨版必須保留的事實、歸屬、揭露、權限與必要背景。
2. 各媒介安排第一注意線索。選用旁白、靜默、構圖或鏡頭；保留無障礙限制。
3. 製作指定腳本或說明，標記擬用效果與估計時長。
4. 要求檔案時，使用可用且已獲授權的工具。開啟／播放成品，或回報待檢視；不支援的製作工作須明列。

**輸出：**各媒介作品、來源對照、產物狀態與缺件。**停止：**指定形式已檢視，或缺能力／輸入；先交付可用說明。**規則：**ST-R01、ST-R03、ST-R07、ST-R11、ST-R14。**依據：**P03、P08、P09。

**試例：**廣播邀請與海報共用日期。合成敲擊不代表曾錄下工作坊。海報專屬黃弧不會成為廣播中的觀察物件。

## W4 · 審核證據與主張

**觸發：**事實、商業、紀錄或教學主張需要審閱。**輸入：**草稿、來源修訂、相關原文、受眾與限制。

1. 拆開複合斷言，逐項核對。
2. 分開檢查存在、修訂、相關性與支持程度。使用 `supported`（現有證據支持此命題）、`contradicted`（證據確立不相容命題）、`insufficient`（現有證據不足以確立此命題）或 `unavailable`（必要證據未提供或無法存取），並說明。這是審閱標籤，不是現有 Rust enum。沒有結果或僅完成編譯，不能建立匯入失敗或平台不支援。W5 改寫的對比、因果與驗證範圍須回到本步核對。
3. 分開直接引文、改述、推論與宣傳提議。保留不確定與範圍限定。
4. 提供有支持的改寫，或保留未解主張。不編造引文填補證據。

**輸出：**主張 → 原文／修訂 → 判斷 → 建議措辭，再附修訂稿。**停止：**每項重要主張都有支持或明列未解處置。**規則：**ST-R01、ST-R02、ST-R10。**依據：**P07、S01。

**試例：**三次內部試驗量到匯入時間，不能建立普遍生產力或可靠度。連結存在不代表措辭通過。

## W5 · 修訂與交接

**觸發：**來源、權限、角色事實或版本選擇改變。**輸入：**基準稿、來源對照／歷史、修改請求與保護選擇。

1. 凍結基準識別碼。分開共用來源修正與單版修改。
2. 列出直接影響與間接效應。必查三類：(a) 未登記的跨稿改述與相對時間；(b) 隨更正數值及分母連動的差值、比例與百分比；(c) 佐證細節縮減或消失後，須同步退縮的緊鄰詮釋。另查後續揭露與構圖依賴：全幅字卡可能遮住原本小窗後仍可見的背景。涵蓋不完整時，檢查整份受影響輸出。
3. 執行已授權的最小完整修訂，包含相依措辭與算術。保留未受影響內容、舊版與已拒絕替案。模糊變更不得默默擴大。凡改寫對比句、因果連接詞或驗證範圍，須以 W4／ST-R02 核對新句；不可將缺件或前段驗證（`insufficient`／`unavailable`）反推為失敗或不支援；只有證據確立與待審主張不相容的命題時，才使用 `contradicted`。引語不再提按鈕時，旁文須退縮至更正引語實際支持的解讀。撤回同意時，移除該段個人經驗及相依改述，不以匿名或換說話者繞過撤回。
4. 交付實際修訂副本；要求原稿時也交付未改副本。顯示 diff、來源變更、待解問題與產物狀態。
5. 可用支援 CLI 時，只使用文件化輸入。直接引用報告與語意審閱分開。

**輸出：**改稿、改／留／審對照、決定與交接說明。**停止：**各受影響稿都有處置，或尚缺決定／能力。**規則：**ST-R02、ST-R03、ST-R08–ST-R11、ST-R14。**依據：**P04、P05、P08、P11、S01。

**試例：**海報與兩版廣播的週六改週日；來源圖與合成敲擊可重用。人工查找隱含「明天」引用。只替插畫 B 改色，不能連 A 一起改。

## W6 · 評估受眾與修訂結果

**觸發：**評估讀者是否察覺選擇，或編輯是否減少錯誤。**輸入：**凍結作品、族群／語言／媒介、主持人獨立答案表、比較條件與實際觀察（若有）。

1. 讀者資料包不附作者意圖或答案，使用中性名稱，平衡首次接觸順序。先問開放問題，再命名比較項目。第一焦點／揭露記 `rating`；推論另記 `inference_status`：`grounded`、`hypothesis`、`unsupported`、`none` 或 `unassessed`。保留各項推論原句與佐證；即使焦點符合，無據斷言仍須記錄。舊紀錄缺推論欄時保持 `unassessed`。
2. 以配對任務及平衡順序比較 `notes` 與 `mapped`。另做 `mapped` 對 `mapped-bounds` 試驗：材料與來源對照相同，只增加該案來源 ID／支持說法／界線列，以誤改／已交回稿數為預先指定主指標。兩組比較與條件分開；接手者不得收到主持人答案或校準範例。修改卡取代舊值後須重查界線。準備／製圖／整理邊界表時間與交接時間分開。提供現成圖的試驗不能代表完整技能效益。
3. 收集實際稿件、回應與時間。保留未完成、分歧與意外解讀。分類有爭議時另請評分者。
4. A/B 分開回報：第一焦點符合數／首次接觸數（`rating`），另列 `inference_status` 各類數量與分母。無據因果斷言 `unsupported` 與 `unassessed` 數量單獨呈現；未評估不能當成有據。交接另報完成／嘗試、漏改／預期改稿、多改／收到且不需改的稿件、誤改／收到稿件、未交／要求稿件，盡可能按條件、情境與修改卡拆列。分母為零時填不適用；兩個閱讀軸及各項交接錯誤率分開。
5. 遵循專案的[閱讀與交接協定](https://github.com/bynanci/storytelling/blob/main/examples/evaluation/README.md)。[來源界線](https://github.com/bynanci/storytelling/blob/main/examples/evaluation/source-boundaries.zh-TW.md)只交給指定交接條件；[account-review 校準範例](https://github.com/bynanci/storytelling/blob/main/examples/studies/account-review/calibration.zh-TW.md)保留給主持人。其中門檻是本地先導決策，並非論文效果量。招募前凍結門檻；決策必須涵蓋漏改、多改、誤改與未交，不能只看速度或漏改。N-01 與這次評估分開。
6. 模型評論只用來提出失敗案例。代理演練標成合成測試。沒有人類觀察時，只交付協定與空白結果欄。

**輸出：**協定或有證據的結果報告，附繼續／縮小／修訂／停止建議與限制。**停止：**預定試驗完成，或沒有觀察資料；不捏造成功參與者。**規則：**ST-R06、ST-R12、ST-R13。**依據：**P03、P05、P10。

**試例：**兩版讀者都先注意日期。保留結果並調整線索；機器順序檢查通過無法推翻觀察。

## 貢獻與拆分條件

流程仍共用來源與修訂概念時，保留單一 router。只有具備獨立觸發條件、自足參考文件、獨立合成評估與維護者，才拆成獨立安裝技能。測試完整複製套件，不只測 repo 相對連結。保留技能授權，以原創摘要引用研究。不要求遠端模型、付費服務或 Rust 才能手動操作。
