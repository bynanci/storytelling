# Umbrella repair workshop

<a name="umbrella-repair-workshop--修傘工作坊"></a>

[繁體中文](workshop-demo.zh-TW.md)

Use one notice, one drawing and one sound to make an invitation, a poster brief and a short audio script. The three original materials use the [skill's MIT license](../LICENSE).

<a name="source-materials--素材"></a>

## Source materials

| ID | Source | What it supplies |
| --- | --- | --- |
| S1 | Event notice | **Saturday: umbrella repair session. Bring one umbrella.** |
| S2 | [Workbench schematic (SVG)](../assets/umbrella-workshop/bench.svg) | A folded blue umbrella lies on the left. A spool of ochre thread lies on the right. |
| S3 | [Two taps (WAV)](../assets/umbrella-workshop/taps.wav) | Two synthetic taps start at about 0.20 and 0.75 seconds. The clip lasts 1.08 seconds. It contains no speech. |

The drawing and sound are separate sources. Pairing them is an editorial choice. The recording does not identify what made the sound.

<a name="try-it--試做"></a>

## Try it

1. Attach S2 and S3 to the conversation.
2. Paste S1 into the conversation.
3. Send the request below. If the host cannot inspect a file, provide its description as supplied text. Mark a missing source when neither file nor description is available.

```text
Use S1–S3 for a neighborhood invitation. Write one sentence that stays within the notice.
Describe a poster that uses the space between the two objects.
Write a two-beat audio script with an informational opening and a poetic alternative.
Give the source IDs for each output. Label invented wording and cues.
If you only read a description, say so.
```

<a name="compare-the-treatments--對照兩種處理"></a>

## Compare the treatments

| Output | Draft | What to check |
| --- | --- | --- |
| Invitation | “Bring one umbrella to Saturday's umbrella repair session.” | S1 gives the day and the requested item. It gives no time, venue, attendance figure or guarantee. |
| Poster brief | Keep the blue umbrella on the left and the spool on the right. Set the invitation in the gap. | The layout of the objects comes from S2. The event text uses S1. The proposed type placement belongs to the design. |
| Informational audio | First say “Saturday is umbrella repair day.” In the second beat, play S3, then say “Bring one umbrella.” | S1 supports the words. The place of S3 between the lines is a proposed edit. |
| Poetic audio | Play both taps. Leave a breath. Say “A small knock, an answer.” Then say “Bring one umbrella on Saturday for the repair session.” | The writer adds the knock and answer as imagery. S3 supplies two sounds. |

These scripts are ready for recording. The poster brief gives art direction. A finished image or audio file requires a suitable tool and an actual file check.

<a name="revision-check--改一處再檢查"></a>

## Revision check

- Change Saturday to Sunday in S1. Update the invitation, poster date and both spoken dates. Keep the layout and the original sound.
- Remove S3 and its description. Deliver the invitation and visual brief. Omit the sound or reserve a provisional cue.
- “100 participants kept 100 umbrellas out of landfill” needs attendance and repair-outcome evidence. Record both gaps. Keep the invitation that S1 supports.
