# Umbrella repair workshop · 修傘工作坊

Use this fictional event to turn one notice, one image and one sound into an invitation, a poster brief and a short audio script. 以下三份素材皆為此範例原創，採用套件的 [MIT 授權](../LICENSE)。可在能讀取附件的 Agent 使用實際檔案，也可以依文字描述演練。

## Source materials · 素材

| ID | Input / 輸入 | What the source supplies / 可以引用的內容 |
| --- | --- | --- |
| S1 | Event notice / 活動文字 | **Saturday — umbrella repair session. Bring one umbrella.** 週六舉辦修傘活動。請帶一把傘。 |
| S2 | [Workbench schematic / 工作檯示意圖（SVG）](../assets/umbrella-workshop/bench.svg) | A folded blue umbrella lies on the left, a spool of ochre thread on the right. 工作檯左側是一把折起的藍傘，右側是一卷赭黃色的線。 |
| S3 | [Two taps / 兩聲敲擊（WAV）](../assets/umbrella-workshop/taps.wav) | 短促敲擊、停頓、再敲一下，沒有說話聲。The two synthesized taps start around 0.20 and 0.75 s. The clip is 1.08 s long. |

S2 is an original drawing and S3 is a synthesized sound effect. Their relationship is an editorial choice. No recording identifies what made the sound. S2 是示意圖，S3 是合成音效。兩者可以在作品中搭配，勿將敲擊描述成工作坊現場錄到的聲音。

## Try it · 試做

Attach S2 and S3 and paste S1 into the agent. If the client cannot inspect an SVG or play a WAV, paste the corresponding description and mark it as supplied text. If neither the file nor its description is available, mark that source as missing and proceed with the available material.

將 S2、S3 附在對話中，並貼上 S1。平台若無法讀圖或收聽，請改貼表內的圖說或聲音描述，並註明依據來自文字。附件與描述皆缺少時，先完成仍有依據的部分。

```text
Use S1–S3 for a neighborhood invitation. Write one source-faithful sentence,
a poster composition that uses the space between the objects, and an audio script
in two beats. Give the audio script one informational and one poetic opening.
Cite the source IDs for each output and label invented wording or cues. If you
could only read a supplied description, say so.
```

```text
用 S1–S3 邀請鄰里居民。寫一句忠於來源的邀請文案、一款運用物件間留白的海報構圖，
以及一份兩段式聲音腳本。聲音腳本另給「直接告知」和「詩意聯想」兩種開場可選。
逐項標記來源及新增的文字或聲音安排。若只能參考圖說或聲音描述，請註明。
```

## Compare the treatments · 對照兩種處理

| Output | Example / 範例 | Check / 檢查 |
| --- | --- | --- |
| Invitation / 邀請文案 | “Bring one umbrella to Saturday’s umbrella repair session.” 「週六修傘，請帶一把傘來。」 | S1 supplies the day and requested item. No time, venue, attendance estimate or repair guarantee has been supplied. |
| Poster brief / 海報構圖 | Keep the folded blue umbrella on the left and thread on the right. Set the invitation in the gap. 保留左傘右線，在中間的留白排入邀請文字。 | The two objects and their positions come from S2. Type placement is a design decision. 活動文案用 S1，排字位置是設計選擇。 |
| Informational audio / 直接告知 | First say “Saturday is umbrella repair day.” In the second beat, play S3, then say “Bring one umbrella.” 第一段先說「週六修傘」。第二段播放敲擊音效，再說「請帶一把傘」。 | S1 provides the words’ factual basis. Placing S3 between lines is a proposed edit. |
| Poetic audio / 詩意聯想 | Play both taps, leave a breath, then say “A small knock, an answer.” In the second beat, say “Bring one umbrella on Saturday for the repair session.” 第一段讓兩聲敲擊先響，空一拍再說「一下敲門，一下回應。」第二段才交代週六修傘、請帶一把傘。 | “Knock” and “answer” are proposed imagery. The source identifies two sounds without identifying their cause. 「敲門」與「回應」屬於修辭。 |

The audio examples are cue sheets for later recording. The poster example is an art-direction brief. 範例交付的是可錄製的提示稿與可排版的構圖說明。要交付圖檔或成音時，需由能產出該格式的工具執行並檢查實際檔案。

## Revision check · 改一處再檢查

- Change S1 from Saturday to Sunday. Update the invitation, the poster’s event text and the spoken date in both treatments. Preserve the picture layout and original sound. 將 S1 的週六改為週日，核對每個出現日期的版本。排版與兩聲敲擊仍可沿用。
- Remove S3 and its description. The invitation and visual brief can still be delivered. Reserve an explicitly provisional sound cue, or omit it. 移除 S3 及其描述後，可在聲音稿標「待選音效」。不要把兩聲敲擊寫為已聽到的事實。
- A claim like “100 participants kept 100 umbrellas out of landfill” requires attendance and repair-outcome evidence. S1–S3 supply neither. 若收到「百人參加，讓百把傘免於丟棄」的標語提案，先標示缺少人數與維修成果紀錄，保留可以立即使用的週六邀請。
